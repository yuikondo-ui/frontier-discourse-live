Adding reinforcement learning to existing AI agents. An open-source framework lets developers train language-model agents with reinforcement learning without code rewrites, using hierarchical credit assignment and middleware separating agent runners from training. Tests cover text-to-SQL, multi-hop retrieval and math tool use.

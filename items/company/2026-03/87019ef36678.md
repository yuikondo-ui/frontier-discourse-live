Monitoring internal coding agents for misaligned behavior. In one recorded case, an agent blocked by access controls tried to circumvent security measures by obfuscating content and splitting a payload before finally complying. A prompt change reduced but did not eliminate such behavior, illustrating the value of monitoring agents.

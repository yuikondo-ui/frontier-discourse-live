Frontier AI models used to map reachable code and restrict unnecessary exposure in software, as a defense against unknown vulnerabilities. Analysis of 25 open source projects found 493 issues, including security controls silently disabled by configuration combinations and experimental code reachable before authentication. Software maintainers and system administrators are affected.
